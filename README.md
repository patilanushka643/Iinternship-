# Alex Morgan — Personal Portfolio

A responsive personal portfolio webpage created for the Week 1 Web Development assignment. It presents a frontend developer's introduction, academic background, skills, and contact details in a clean, editorial-style layout.

## Features

- Semantic HTML5 structure using `header`, `nav`, `main`, `section`, and `footer`
- Hero section with navigation, profile image, introduction, and calls to action
- About, education, skills, and contact sections
- Accessible labels, alt text, heading hierarchy, and keyboard-friendly links
- Responsive layout using CSS Grid, Flexbox, and mobile breakpoints
- Modern color palette, typography, skill tags, hover transitions, and smooth scrolling
- Contact form with email submission support

## Tech stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, media queries, transitions)
- Google Fonts: Space Grotesk and DM Sans

## Setup

1. Place `index.html`, `style.css`, and this `README.md` in the same folder.
2. Add a profile image named `profile.jpg` beside `index.html`.
3. Open `index.html` in a browser, or use a local development server such as VS Code Live Server.
4. Update the placeholder name, biography, education, social URLs, and email address in `index.html` for personal use.

No build tools or dependencies are required.
